---

# Description

Discovery captures what exists.

Architecture findings identify recurring patterns.

Validated patterns become candidates for reusable standards.

Engineering Knowledge captures proven engineering practices independent of any single project.

---

# Philosophy

Engineering knowledge should emerge through validation rather than assumption.
