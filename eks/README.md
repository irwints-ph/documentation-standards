# What is EKS?

The **Engineering Knowledge System (EKS)** is a growing body of engineering knowledge.

Unlike project documentation, EKS focuses on understanding **engineering itself**.

It captures the philosophies, methodologies, patterns, practices, and lessons learned through real engineering work.

Its purpose is simple:

> Help engineers learn faster, preserve knowledge longer, and continuously improve together.

---

# Guiding Principle

> Engineering knowledge should outlive the engineers who created it.

Knowledge should become an organizational capability—not an individual's memory.

# AI-Assisted Engineering

EKS views AI as an engineering collaborator.

AI assists with:

* Discovery
* Learning
* Documentation
* Organization
* Pattern recognition
* Knowledge preservation

Engineering judgment remains a human responsibility.

# Design Principles

EKS is guided by several principles.

* Knowledge grows through engineering experience.
* Learning should accompany implementation.
* Evidence should validate methodologies.
* Knowledge should remain reusable.
* Organizational learning should continuously improve.
