# 📚 Documentation System Navigation

---

## Documentation Flow

```text
                    roadmap.md

Purpose:
Where are we going?

Contains:
- Vision
- Long-term goals
- Milestones
- Planned evolution


        │
        ▼


              where-we-are-now.md

Purpose:
Where are we today?

Contains:
- Current activity
- Current milestone
- Current focus
- Resume point
- Links to detailed records


        │
        ▼


          registry/current-standards.md

Purpose:
What is currently accepted?

Contains:
- Accepted standards
- Companion documents
- Supporting references
- Standard status overview


        │
        ▼


          current-standards/

Purpose:
Where are the standards?

Contains:
- Official engineering standards
- Companion reference documents


        │
        ▼


             references/

Purpose:
How do we perform common tasks?

Contains:
- Command references
- Operational guides
- Quick references
