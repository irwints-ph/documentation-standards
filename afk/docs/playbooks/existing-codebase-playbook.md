# 📋 Existing Codebase Playbook

> **Operational checklist for AFK-assisted discovery of an existing software project.**

---

## Purpose

Use this Playbook once you are already familiar with the AFK methodology.

If this is your first time using AFK, complete:

➡️ `existing-codebase-learning-path.md`

---

# AFK Workflow

```text
Wish
    ↓
Project Context
    ↓
Discovery
    ↓
Grant
    ↓
Build
    ↓
Observation
    ↓
Next Wish
```

---

# Pre-Session

## ☐ Review Current WWAN

Read:

- `wwan.md`

Understand:

- Current state
- Active milestone
- Outstanding work
- Resume point

---

## ☐ Define the Wish

Document:

- What is the objective?
- What problem are we solving?
- What outcome is expected?

---

## ☐ Gather Context

Prepare:

- Project overview
- Folder structure
- Existing documentation
- Configuration
- Relevant source files

---

# Discovery

## ☐ Begin Discovery

Provide:

- Project Context
- Existing Source Material
- Initial Wish

Request Discovery.

Expected outputs:

- Component inventory
- Responsibilities
- Dependencies
- Unknowns
- Findings

---

## ☐ Validate Discovery

Confirm:

- ☐ Components identified
- ☐ Responsibilities accurate
- ☐ Relationships documented
- ☐ Unknowns captured
- ☐ Assumptions minimized

If incomplete:

→ Continue Discovery.

---

## ☐ Complete Discovery

Authorize creation of:

- ☐ Grant Strategy
- ☐ Initial Architecture
- ☐ Build Plan

No implementation yet.

---

# Build

## ☐ Review Planning

Review:

- Grant Strategy
- Initial Architecture
- Build Plan

Approve or refine before implementation.

---

## ☐ Begin Build

Authorize implementation.

Implementation should follow the approved Build Plan.

If unexpected discoveries occur:

→ Return to Discovery.

---

# Observation

## ☐ Evaluate Results

Capture:

- What changed?
- What was learned?
- Remaining questions
- Reusable knowledge

---

## ☐ Update WWAN

Record:

- Current state
- Completed work
- Next milestone
- Resume point

---

## ☐ Record Session

Create or update:

- Session Record

Include:

- Summary
- Decisions
- Artifacts produced
- Lessons learned

---

## ☐ Capture Next Wish

Document:

- Future improvements
- Follow-up work
- New discoveries

This becomes the starting point for the next AFK session.

---

# Session Deliverables

Before ending the session, confirm:

## Discovery

- ☐ Wish documented
- ☐ Project Context documented
- ☐ Discovery completed
- ☐ Discovery validated

## Planning

- ☐ Grant Strategy created
- ☐ Initial Architecture created
- ☐ Build Plan approved

## Engineering

- ☐ Implementation completed
- ☐ Observation completed

## Continuity

- ☐ WWAN updated
- ☐ Session Record completed
- ☐ Next Wish documented

---

# Remember

✔ Understand before modifying.

✔ Discover before judging.

✔ Validate before implementing.

✔ Preserve knowledge continuously.

✔ Treat AI as an engineering collaborator.

---

> **Understand first. Build second. Learn always.**
