# 🛠️ Procedure — Initialize an Engineering Project

# Choose an Initialization Method

## Option 1 — Use the AFK Initialization Tool

Run:

- [`../../../_tools/afk-init.cmd`](../../../_tools/afk-init.cmd)

The tool creates the recommended project foundation.

The generated files and folders become part of your local project.

---

## Option 2 — Create It Manually

Create the following minimum artifacts:

```text
README.md
roadmap.md
wwan.md

docs/
    discovery/
    registry/
```
