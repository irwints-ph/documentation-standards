# 🌊 Assisted Flow of Knowledge (AFK)

> *Understand first. Build second. Learn always.*

---

# Welcome

Welcome to the **Assisted Flow of Knowledge (AFK)**.

AFK is a collaboration framework designed for Human Engineers and AI Collaborators to work together while preserving engineering understanding.

AFK is not a project.

AFK is **how projects are collaboratively understood, built, observed, and improved.**

---

# Before You Begin

Do not begin by writing code.

Do not begin by generating documentation.

Begin by understanding where the project currently is.

Engineering should continue from existing understanding rather than reconstruct it.

# Core Collaboration Concepts

Every AFK collaboration is built around several core concepts.

## 📍 WWAN

Where We Are Now

Provides the current operational snapshot.

---

## 🌟 Wish

Defines the engineering objective currently driving the project.

---

## 🔍 Discovery

Understand the engineering problem before implementation.

---

## 🏗️ Build

Create the smallest useful implementation.

---

## 👀 Observation

Allow reality to improve engineering decisions.

---

## ✅ Grant

Determine whether the original wish has been achieved.

---

# Collaboration Flow

Every AFK session naturally follows this flow.

```text
Start Collaboration

↓

Understand

↓

Discover

↓

Build

↓

Observe

↓

Grant

↓

Next Wish
```

Not every session performs every activity.

The current project state determines the appropriate entry point.

---

# Guiding Principles

AFK encourages collaborators to ask:

* What are we trying to grant?
* What already exists?
* What has already been learned?
* What is the smallest useful implementation?
* What observation are we trying to create?

---

# Philosophy

AFK believes:

* Context reduces assumptions.
* Understanding precedes implementation.
* Observation improves engineering.
* Knowledge should be preserved.
* Collaboration should continue naturally across people, AI collaborators, and time.

# For AI Collaborators

AFK is designed so that a new collaboration should begin with understanding rather than prompting.

The prompt should introduce AFK.

AFK should provide the collaboration process.

The project should provide the engineering knowledge.

---

# Closing Thought

Software is built one implementation at a time.

Engineering knowledge is built one observation at a time.

AFK exists to preserve both.
