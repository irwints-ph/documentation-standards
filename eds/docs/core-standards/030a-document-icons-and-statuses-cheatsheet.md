# Quick Rules

### Document Icons

- One document icon only.
- Place it in the document title.
- Use the icon matching the document's primary purpose.

### Status Icons

- One lifecycle status only.
- Keep it in the Metadata table.
- Update it whenever the document reaches a new lifecycle stage.
