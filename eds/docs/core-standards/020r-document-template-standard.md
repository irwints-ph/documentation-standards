# Purpose

This document provides a quick reference for selecting the appropriate document template defined in:

**020 – Document Template Standard**

---

# Document Categories

| Category | Purpose |
|----------|---------|
| Specification Documents | Define reusable engineering rules |
| Knowledge Documents | Capture and communicate engineering understanding |

---

# Specification Documents

Use when the document defines engineering governance.

Examples:

- Standards
- Policies
- Procedures
- References

Recommended layout

```text
Title

↓

Metadata

↓

Purpose

↓

Content

↓

References
```

# Knowledge Documents

Use when the document helps engineers learn or collaborate.

Examples:

- Guides
- Journeys
- Learning Paths
- Playbooks
- WWAN

Recommended layout

```text
Title

↓

Guiding Principle

↓

Purpose

↓

Content

↓
```

# Choosing the Correct Template

| If the document primarily... | Use |
|------------------------------|-----|
| Defines reusable engineering rules | Specification |
| Explains concepts | Knowledge |
| Guides implementation | Knowledge |
| Supports learning | Knowledge |
| Captures operational context | Knowledge |
| Defines governance | Specification |

---

# Quick Checklist

Before publishing:

- □ Is the correct template category selected?
- □ Does the document communicate purpose immediately?
- □ Is metadata in the correct location?
- □ Are related documents linked instead of duplicated?
- □ Is the document easy for both humans and AI to navigate?
