# 📖 WWAN — Operational Context Standard (Quick Reference)

> **WWAN captures where engineering work stands today so it can resume tomorrow.**

---

# Purpose

Provide a concise reference for creating and maintaining a **Where We Are Now (WWAN)** document.

A WWAN records the current operational context of a project, allowing engineers and AI collaborators to resume work without reconstructing prior sessions.

---

# Core Principles

- Capture the current operational state.
- Record only information needed to continue work.
- Keep the document concise.
- Update at meaningful milestones.
- Link to supporting documents instead of duplicating content.

---

# Recommended Structure

A WWAN typically includes:

1. **Current Objective**
2. **Current State**
3. **Recent Progress**
4. **Current Focus**
5. **Next Wishes**
6. **Resume Point**
7. **Notes** *(optional)*

---

# Writing Guidelines

## Focus on Today

Describe where the project is now.

Avoid turning the WWAN into a project history.

---

## Keep It Actionable

Record:

- current milestone
- active work
- immediate priorities
- next logical steps

Avoid lengthy explanations.

---

## Link Instead of Repeat

Reference supporting documents such as:

- README
- Roadmap
- Playbooks
- Journeys
- Standards

Do not duplicate their content.

---

## Update Regularly

Update the WWAN when:

- a milestone is completed
- priorities change
- significant discoveries occur
- work is paused
- work resumes

---

# Relationship to AFK

Within AFK, the WWAN acts as the operational handoff between collaboration sessions.

It enables both humans and AI collaborators to resume productive work quickly.

---

# Relationship to EDS

The WWAN is an Engineering Standard within the Engineering Documentation System.

It follows the standard document template while serving a unique operational purpose.
