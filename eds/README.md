# What is EDS?

The **Engineering Documentation System (EDS)** provides a reusable framework for documenting engineering knowledge in a consistent, maintainable, and AI-friendly way.

EDS is technology independent.

It can be applied to any software project regardless of language, framework, platform, or architecture.

Its purpose is simple:

> Preserve engineering understanding before it is forgotten.

---

# Guiding Principle

> Documentation is not the goal.

> **Understanding is.**

Documentation is one of the artifacts produced by understanding.

# Documentation Structure

## Core Standards

Reusable standards that define **how documentation is written**.

Examples include:

* Documentation System Overview
* Documentation Levels
* Numbering
* Templates
* Naming
* References
* Git Workflow

---

## Engineering Standards

Reusable standards that define **how engineering systems are documented**.

Examples include:

* Source Documentation
* WWAN
* Folder Discovery
* Architecture Findings
* Validation

---

## Operational Documents

Every project built using EDS typically contains:

* README
* roadmap
* scratch
* WWAN

These documents provide operational continuity throughout the engineering lifecycle.

# Relationship to the Engineering Knowledge Ecosystem

EDS is one part of the Engineering Knowledge ecosystem.

| System   | Purpose                                   |
| -------- | ----------------------------------------- |
| **AFK**  | Discover engineering knowledge            |
| **EDS**  | Document engineering knowledge            |
| **EKS**  | Organize engineering knowledge            |
| **EKPP** | Publish engineering knowledge *(planned)* |

Each system has a distinct responsibility while supporting the others.

---

# Documentation Philosophy

EDS encourages documentation that is:

* Human-friendly
* AI-friendly
* Repository-independent
* Language-independent
* Framework-independent
* Incrementally adoptable
* Sustainable

Documentation should remain useful long after the original implementation.

# Design Principles

EDS is built around several engineering principles.

* Discover before modifying.
* Understand before documenting.
* Validate with evidence.
* Preserve knowledge continuously.
* Maintain consistency without restricting engineering creativity.
* Build documentation that survives projects and people.
