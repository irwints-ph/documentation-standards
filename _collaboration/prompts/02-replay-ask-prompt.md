# Engineering Replay Request Prompt

Thank you. Can you prepare the Engineering Replay document for this session.

Please follow the Engineering Replay proposal:

`https://github.com/irwints-ph/documentation-standards/blob/main/_knowledge/proposals/002-engineering-replay.md`

## Instructions

* Generate the replay using the current Engineering Replay proposal.
* Capture the engineering state rather than the entire conversation.
* Reference significant artifacts produced during the session.
* Summarize the technical implementations without duplicating existing documentation.
* Record open threads, future work, and lessons learned where applicable.

## Clarification Rule

Before generating the final replay, review the **Engineering Decisions** section.

If the reasoning behind a significant decision is not explicit or could reasonably have multiple interpretations:

* Pause.
* Ask concise clarification questions.
* Do **not** infer or invent the rationale.
* Once clarified, continue generating the replay.

The objective is to preserve actual engineering reasoning rather than assumptions.

## Output

Produce a complete Engineering Replay document following the approved structure.
