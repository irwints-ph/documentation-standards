# Future Discovery

Discovery is not finished forever.

It simply pauses while implementation begins.

Future Discovery should emerge from:

```text
Build

↓

Experiment

↓

Observe

↓

Learn

↓

New Discovery

↓

Next Wish
```

This allows operational experience—not assumption—to guide the evolution of EKPP.

# Guiding Principle

Discovery is considered complete not when every possible question has been answered,

but when enough understanding exists to confidently grant the current active wish.

As always:

> **Understand first. Build second. Learn always.**

And after building...

> **Experiment. Observe. Learn. Improve.**
