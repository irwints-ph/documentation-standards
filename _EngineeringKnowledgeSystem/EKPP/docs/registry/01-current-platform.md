# 📄 Current Platform

---

## Purpose

This document describes the current publishing platform used by EKPP.

It records the existing environment before it is replaced by future EKPP publishing capabilities.

---

## Current Platform

The current Engineering Knowledge website is hosted using Amazon Web Services (AWS).

The deployed website consists of a small collection of HTML, CSS, JavaScript, and deployment support files.

These files have been preserved inside the repository as a reference baseline.

---

## Current State

Status

✅ Production

Technology

* Static HTML
* CSS
* JavaScript
* AWS Static Website Hosting

---

## Relationship to EKPP

The existing platform remains the operational production website.

The new implementation under the `website/` folder is intended to gradually replace this platform as wishes are granted and validated.

---

## Future Direction

As EKPP evolves, publishing should become an automated process rather than a manually maintained collection of HTML files.

Until then, the existing platform remains the production reference.
