# 📍 Current Platform Registry

---

## Purpose

This registry documents the current publishing platform used by the Engineering Knowledge Publishing Portal (EKPP).

It provides collaborators with a clear understanding of:

* the current production website,
* the active implementation,
* and how both relate during the Build process.
