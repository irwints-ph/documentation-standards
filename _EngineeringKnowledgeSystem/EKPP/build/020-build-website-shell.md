# Purpose

This Build Guide produces the first observable output of the Engineering Knowledge Publishing Portal.

The objective is **not** to build the complete portal.

The objective is to create the smallest useful implementation that allows observation, validation, and collaborative refinement.

---

# Build Objective

Create the initial Website Shell.

The Website Shell serves as the first visible representation of EKPP and establishes the foundation upon which future publishing capabilities will be built.

---

# Build Scope

This build includes:

* Homepage
* Basic styling
* Basic JavaScript placeholder
* Project branding
* Initial content

This build intentionally excludes:

* Markdown publishing
* Navigation system
* Search
* Theme support
* Responsive optimization
* Content generation
* Automation
* AI integration

Those belong to future wishes.

# Success Criteria

This Build is considered successful when:

* the homepage renders successfully,
* the project identity is visible,
* the active wish is represented,
* implementation evidence has been captured,
* observations have been recorded.

---

# Out of Scope

Do not:

* improve visual design beyond readability,
* build future portal features,
* optimize for AI consumption,
* introduce automation,
* anticipate future wishes.

The purpose of this Build is observation.

---

# Observation

After implementation, ask:

* Does the homepage clearly communicate EKPP's purpose?
* Is the project identity immediately understandable?
* What feels unnecessary?
* What feels missing?
* What should remain unchanged?

Record observations before introducing additional functionality.

# Exit Condition

Pause this Build after:

* the Website Shell has been implemented,

* observations have been recorded.

Only then should the next wish be considered.
