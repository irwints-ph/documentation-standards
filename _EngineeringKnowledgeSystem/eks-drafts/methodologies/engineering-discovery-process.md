# Purpose

Defines the recommended workflow for documenting an existing engineering system.

---

# Discovery Flow

Repository Inventory

↓

Folder Validation

↓

File Documentation

↓

Architecture Observation

↓

Cross-file Validation

↓

Pattern Discovery

↓

Architecture Finding

↓

Candidate Documentation Standard

↓

Engineering Knowledge

---

# Characteristics

The process is iterative.

Discovery may revisit earlier steps as additional understanding is gained.

Architecture findings should be supported by multiple implementation examples whenever possible.

---

# Goal

Transform implementation knowledge into reusable engineering knowledge.
