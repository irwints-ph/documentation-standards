# Vision

Create a practical knowledge system that helps people:

- Discover
- Learn
- Build
- Validate
- Preserve
- Reuse

knowledge across engineering and eventually other domains.

The objective is not to replace learning.

The objective is to improve how people acquire and organize knowledge.

## Emerging AFK Principles

Current observations include:

- Knowledge is attainable.
- Curiosity precedes knowledge.
- Small discoveries accumulate.
- Preserve reasoning, not only conclusions.
- Evidence before opinion.
- Ask one more question.
- Protect curiosity.
