# Purpose

Provide a quick copy/paste reference for the standardized icons used throughout the Engineering Documentation System.

This document supplements the Document Icon Standard and is intended for everyday documentation work.

---

# 📚 Document Type Icons

| Icon | Copy / Paste | Document Type | Typical Folder | Purpose |
|------|--------------|---------------|----------------|---------|
| 📄 | `📄 README` | README | Repository / Folder | Entry point |
| 📘 | `📘 Standard` | Standard | docs/standards | Engineering standards |
| 📖 | `📖 Knowledge` | Knowledge | docs/knowledge | Concepts and explanations |
| 🛠️ | `🛠️ Procedure` | Procedure | docs/procedures | Step-by-step guides |
| 🏛️ | `🏛️ Architecture` | Architecture | docs/history/architecture | Architecture decisions |
| 🗓️ | `🗓️ Session` | Session | docs/history/session | Development journal |
| 🗺️ | `🗺️ Roadmap` | Roadmap | docs/roadmap | Future planning |
| 📑 | `📑 Design` | Design | docs/design | Proposed designs |
| ⚙️ | `⚙️ Internals` | Internals | docs/internals | Implementation details |
| 🌿 | `🌿 Git History` | Git History | docs/history/git | Repository history |
| 🆘 | `🆘 Knowledge Base` | Knowledge Base | docs/kb | Troubleshooting |

| 📦 | `📦 Release Notes` | Release Notes | docs/releases | Release history |

# 🚦 Document Status Icons

| Icon | Copy / Paste | Status | Meaning |
|------|--------------|--------|---------|
| 📝 | `📝 Planning` | Planning | Work has not started |
| 🚧 | `🚧 In Progress` | In Progress | Currently being developed |
| 👀 | `👀 Under Review` | Under Review | Awaiting approval |
| 🧪 | `🧪 Experimental` | Experimental | Prototype or proof of concept |
| ⏸️ | `⏸️ On Hold` | On Hold | Temporarily paused |
| ⚠️ | `⚠️ Blocked` | Blocked | Waiting on dependency |
| ✅ | `✅ Accepted` | Accepted | Approved engineering document |
| 📦 | `📦 Official` | Official | Current published engineering standard |
| 🔄 | `🔄 Superseded` | Superseded | Replaced by a newer document |
| ❌ | `❌ Cancelled` | Cancelled | No longer proceeding |
| 🗃️ | `🗃️ Archived` | Archived | Historical reference |

# Quick Rules

✅ One Document Type icon per document

✅ One Status icon per document

✅ Place the Document Type icon in the title

✅ Place the Status icon in the Status section

✅ Use only standardized icons

❌ Do not invent project-specific icons

❌ Do not combine multiple Document Type icons
