# Purpose

Define the standardized document icons and status icons used throughout the Engineering Documentation System.

Icons and statuses provide a consistent visual language that improves readability, navigation, document recognition, and lifecycle visibility.

---

# Standard

## One Document Type Icon

Every document shall have **one** Document Type icon.

The Document Type icon identifies the document's primary purpose.

Example

```markdown
# 📘 Documentation System Overview
```

---

## One Status Icon

Every document shall have **one** Status icon.

The Status icon represents the document's current lifecycle state.

Example

```markdown
## Status

**As of:** MM.DD.YYYY HH:MM TZ

✅ Accepted
```

---

## Placement

Icons shall be used consistently throughout the documentation system.

| Element        | Standard              |
| -------------- | --------------------- |
| Document Title | Document Type icon    |
| Status Section | Status icon           |
| Tables         | Icon optional         |
| Body Text      | Optional when helpful |

---

## Icon Categories

The Engineering Documentation System defines two categories of standardized icons:

* Document Type Icons
* Document Status Icons

The complete list is maintained in the companion cheatsheet.

## Cheatsheet

030a-document-icons-and-statuses-cheatsheet.md

---

## Principles

* Use one Document Type icon per document.
* Use one Status icon per document.
* Do not combine multiple Document Type icons.
* Do not use icons decoratively.
* Use only standardized icons.
* Keep icon usage consistent across repositories.
